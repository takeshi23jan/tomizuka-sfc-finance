### 2. 補助金申請様式（`02hojokinshinsei2.xlsx`）の「-」表示

出典: [2026-08-04_ConfirmationToCity.eml](2026-08-04_ConfirmationToCity.eml), [2026-08-05_AnswerFromCity.eml](2026-08-05_AnswerFromCity.eml)

- 質問：該当欄が「-」と表示される件は、雑収入（算定対象外）に含めるべきものか
- 回答：対象外経費の話ではなく、**補助金額算定の1,000円未満切り捨てルール**によるもの
  - 補助金算定額：87,600円（対象経費）－46,000円（参加費等収入）＝41,600円 → 1,000円未満切り捨てで41,000円
  - 差額600円が収支不足として「-600円」表示される
  - 対応策：消耗品費を30,000円→29,400円に減らせば差額が0円になる

### 5. 制度見直し要望とAmazon購入時の証憑書類

出典: [2026-08-13_ConfirmationToCity.eml](2026-08-13_ConfirmationToCity.eml), [2026-08-13_AnswerFromCity.eml](2026-08-13_AnswerFromCity.eml)

### 6. 立替金・寄付金の会計処理手続き

出典: [2026-08-14_ConfirmationToCity.eml](2026-08-14_ConfirmationToCity.eml), [2026-08-14_AnswerFromCity.eml](2026-08-14_AnswerFromCity.eml)

- 質問①：補助金入金までのクラブ資金不足の立替について、会計処理の手順が分からない
- 回答①：以下の流れを想定
  1. 消耗品等を購入
  2. クラブの誰かが立て替えて代金を支払う
  3. クラブ名義の領収書を受け取る
  4. 補助金が入金されるまで、立替者が領収書を保管
  5. 補助金がクラブの通帳に入金される
  6. クラブ通帳から立替金額を出金し、立替者に渡す（精算）
  7. 立替金と引き換えに領収書をクラブに渡す
  8. 領収書を「立替払請求書兼受領書」に貼付け、立替者に受領の署名・押印をしてもらう
- 質問②：1,000円未満の寄付金について、領収書等の証憑書類は必要か
- 回答②：領収書発行は義務ではない。認定クラブへの寄付は所得税控除の対象外のため、**領収書を発行する必要はなく、帳簿記載のみでよい**

### 7. 謝金の立替に関する会計処理

出典: [2026-08-16_ConfirmationToCity.eml](2026-08-16_ConfirmationToCity.eml), [2026-08-18_AnswerFromCity.eml](2026-08-18_AnswerFromCity.eml)

- 質問：今年度は会費収入46,000円に対し謝金支払いが約60,000円見込みで、謝金の立替が発生する可能性が高い。以下の案について会計処理上の問題有無と、書類（`02hojokinshinsei2.xlsx`等）への反映方法・証憑管理を確認
  1. 桑原 → クラブ口座に謝金赤字補填分を入金
  2. クラブ口座 → 指導者へ謝金支払い
  3. クラブ口座 → 税務署に源泉徴収分を納付
  4. 市 → クラブ口座に補助金入金
  5. クラブ口座 → 桑原に赤字補填分を返金（精算）
- 回答：
  - まずは集金の前倒し・謝金支払いの後ろ倒し・概算払いの活用などで、**立替が生じないような計画を優先して検討**してほしい
  - 個人が指導者謝金を立て替えることには市としても違和感があるが、やむを得ず立替が生じた場合は**消耗品等と同様の処理**でよい
  - 提案の「クラブ口座への借入金繰入」は不可能ではないが難しい。一般的には入金前に**「意思決定の記録（議事録）」と「契約の記録（金銭消費貸借契約書）」が必ずセットで必要**
    1. 理事会・総会で借入の金額・理由を決議し議事録を残す
    2. 貸主（役員個人等）・借主（クラブ代表者）間で金銭消費貸借契約書を2通取り交わす（無利息なら印紙不要）
    3. クラブ名義通帳に振込で入金し証拠を残す
    4. 補助金入金後、速やかに返済し領収書（精算書）を発行、振込記録を残す
  - ここまで厳密でなくてよいが、**少なくとも意思決定・契約の記録は残すこと**。難しい場合は消耗品等と同様の処理でも可
  - 繰入時の勘定科目：借入金の科目がないため**雑収入**に計上。精算時は収入・支出を増やさないよう**雑収入をマイナス処理**する

⚠️ 要確認（未回答）：桑原氏は「参加費を変更する場合、『はまクル認定クラブ申請事項変更届』（`shinse5.docx`）の提出が必要と思われる」と述べているが、この点について市からの明示的な確認回答はまだ得られていない（2026-08-18時点）。

### 8. 消耗品・謝金の立替処理に関する解釈整理（桑原-AI共同検討・2026-08-19時点で整理、送信済・回答待ち）

⚠️ この節はメールでの確定回答ではなく、既存のやり取り（セクション5・6・7）を読み直した上での**桑原-AI解釈の整理**です。以下のQ1a・Q1b・Q2を含む再確認メールは**市へ送信済み**（2026-08-25時点で市からの回答待ち）。回答が届き次第、内容を更新します。

- **論点**：8/18回答の「やむを得ず立替が生じた場合は消耗品等と同様の処理でよい」という一文から、「市は消耗品も常に立替で購入する前提なのでは？（桑原氏の元の理解＝消耗品は会費から直接支払い、謝金のみ立替、と矛盾するのでは？）」という疑念が生じた。
- **整理した結論**：矛盾はないと考えられる。
  - 8/14の質問（[2026-08-14_ConfirmationToCity.eml](2026-08-14_ConfirmationToCity.eml)）はそもそも「クラブ資金不足の立替」という**一般論**として聞いており、消耗品限定の質問ではなかった。
  - 8/14回答（[2026-08-14_AnswerFromCity.eml](2026-08-14_AnswerFromCity.eml)）はその一般論を説明する際に「**例**　消耗品等を購入 → …」と、消耗品を**例示**として使っただけ。
  - よって8/18回答の「消耗品等と同様の処理」は、「消耗品を買うときに使う立替の一般的な処理テンプレートを、謝金の立替にも流用してよい」という意味であり、「消耗品は必ず立替で買う」という意味ではない。
  - 立替が発生するかどうかは費目ではなく**クラブの手元資金が足りるかどうか**で決まる：消耗品費（約30,000〜40,000円）は9月の会費収入（46,000円）で賄えるため立替不要、謝金（年間見込み約60,000円）は会費収入だけでは不足するため立替が生じる可能性が高い。
- **単式簿記の記帳について**：「消耗品等と同様の処理」は単式簿記（出納帳）への記帳だけでは完結しない。以下の3点セットが必要という理解：
  1. 原始証憑の保管（指導者の受領書・源泉税納付記録など）
  2. 精算時に「立替払請求書兼受領書」へ証憑を貼付け、立替者に受領の署名・押印をしてもらう（単式簿記とは別の書類）
  3. クラブ口座から実際にお金が動いた精算日に、単式簿記（出納帳）へ支出として記帳（摘要欄に立替者名・本来の支払日を記載）
  - なお「消耗品等と同様の処理」ルートを取る場合、8/18回答にあった「議事録」「金銭消費貸借契約書」「雑収入への計上」（＝借入金繰入方式）は不要という理解。
  - ①②③の「立替→精算」テンプレート自体は消耗品の実際の支払い方法（立替か直接支払いか）に依存しないため、謝金に関する質問（Q2）は消耗品の支払い方法に関する質問（Q1a・Q1b）と**切り離して独立に確認できる**と整理し直した。

  - Q1a：消耗品購入時、クラブ名義口座から引き出した現金でのコンビニ払い（個人カード不使用）は「立替」に該当せず、「立替払請求書兼受領書」は不要という理解でよいか
