### 2. 補助金申請様式（`02hojokinshinsei2.xlsx`）の「-」表示

出典: [2026-08-04_ConfirmationToCity.eml](2026-08-04_ConfirmationToCity.eml), [2026-08-05_AnswerFromCity.eml](2026-08-05_AnswerFromCity.eml)

- 質問：該当欄が「-」と表示される件は、雑収入（算定対象外）に含めるべきものか
- 回答：対象外経費の話ではなく、**補助金額算定の1,000円未満切り捨てルール**によるもの
  - 補助金算定額：87,600円（対象経費）－46,000円（参加費等収入）＝41,600円 → 1,000円未満切り捨てで41,000円
  - 差額600円が収支不足として「-600円」表示される
  - 対応策：消耗品費を30,000円→29,400円に減らせば差額が0円になる

### 3. 収支決算書での同様の不足額処理

出典: [2026-08-05_ConfirmationToCity.eml](2026-08-05_ConfirmationToCity.eml), [2026-08-06_AnswerFromCity.eml](2026-08-06_AnswerFromCity.eml)

- 質問：収支決算書は実績ベースのため、予算書のように金額調整ができないのでは
- 回答：その通り。決算書はマイナスにならないよう**予算内に実績を抑えるしかない**。支出が予算を超過する場合は収入を見直すしかなく、
  - 3月会費（補助金の算定対象外収入）を増額する
  - 寄付金等を募る
  のいずれかの方法で対応

### 5. 制度見直し要望とAmazon購入時の証憑書類

出典: [2026-08-13_ConfirmationToCity.eml](2026-08-13_ConfirmationToCity.eml), [2026-08-13_AnswerFromCity.eml](2026-08-13_AnswerFromCity.eml)

- 制度見直し要望（桑原氏より）：
  - 補助金は赤字補填の制度のため、最終的に誰か（本年度は桑原氏想定）が立替を行う必要がある
  - 補助金は1,000円未満切り捨てのため、赤字回避には誰かが寄付金を拠出する必要がある
  - 来年度引継ぎ時にこの状況を引き継ぐのは望ましくない
  - → 市回答：本制度は国税・市税からの補助制度であり、**市単独では制度設計を変更できない**。国へ要望は継続しているが、すぐの修正は難しい
  - 寄付金回避の代替策：参加費を2,000円→2,200円にすれば差額0円になる（ただし参加費増額分、補助金は減額される）
- Amazon購入時の証憑書類：
  - 見積書＝Amazon金額がわかるページのスクリーンショットで可
  - 請求書＝amazon請求書サンプル.pdf、支払証明＝amazon領収書サンプル.pdfの形式でよい旨、市が確認
  - 桑原氏のカードで支払う場合は市HPの「領収書台紙・立替金請求書兼受領書（見本）」を活用。**ポイント付与は不可**
  - ⚠️ 添付されたサンプルは8月購入日のものだが、8月は補助対象期間外のため実際の支払いはできない（サンプルとしての位置づけ）

### 6. 立替金・寄付金の会計処理手続き

出典: [2026-08-14_ConfirmationToCity.eml](2026-08-14_ConfirmationToCity.eml), [2026-08-14_AnswerFromCity.eml](2026-08-14_AnswerFromCity.eml)

- 質問①：補助金入金までのクラブ資金不足の立替について、会計処理の手順が分からない
- 回答①：以下の流れを想定
  1. 消耗品等を購入
  2. クラブの誰かが立て替えて代金を支払う
  3. クラブ名義の領収書を受け取る
  4. 補助金が入金されるまで、立替者が領収書を保管
  5. 補助金がクラブの通帳に入金される
  6. クラブ通帳から立替金額を出金し、立替者に渡す（精算）
  7. 立替金と引き換えに領収書をクラブに渡す
  8. 領収書を「立替払請求書兼受領書」に貼付け、立替者に受領の署名・押印をしてもらう
- 質問②：1,000円未満の寄付金について、領収書等の証憑書類は必要か
- 回答②：領収書発行は義務ではない。認定クラブへの寄付は所得税控除の対象外のため、**領収書を発行する必要はなく、帳簿記載のみでよい**

⚠️ 要確認（未回答）：桑原氏は「参加費を変更する場合、『はまクル認定クラブ申請事項変更届』（`shinse5.docx`）の提出が必要と思われる」と述べているが、この点について市からの明示的な確認回答はまだ得られていない（2026-08-14時点）。
