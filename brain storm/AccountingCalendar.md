```

12月 ├─ 源泉税③（11月分）納付 ★
1月  ├─ 源泉税④（12月分）納付 ★
2月  ├─ 源泉税⑤（1月分）納付 ★ / 補助対象期間終了
3月  ├─ 源泉税⑥（2月分）納付 ★ / 実績報告 / 補助金振込
4月  └─ 源泉税⑦（3月分）納付 ★（最終） / 決算・引継ぎ

★ = 毎月10日が期限の源泉税納付（計7回・各612円）
```
